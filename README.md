# CrewAI Flask Research API

## Overview

This project demonstrates building a research API using Flask integrated with CrewAI workflows and agents.

## Objectives

* Understand Flask API integration with CrewAI
* Build research-based API workflows
* Handle request and response processing
* Execute CrewAI workflows through API endpoints

## Technologies Used

* Python
* Flask
* CrewAI
* YAML Configuration
* OpenAI API

## Steps Followed

1. Installed Flask, CrewAI, and dependencies.
2. Created API project structure.
3. Configured API routes and endpoints.
4. Connected CrewAI workflows with Flask.
5. Executed API requests successfully.
6. Verified request-response outputs.

## Problems Faced

* API routing issues
* Dependency installation errors
* Request handling problems
* Workflow integration confusion

## Solutions

* Corrected route configurations
* Updated dependencies properly
* Verified endpoint handling
* Tested API execution step by step

## Outcome

Successfully implemented a Flask-based research API integrated with CrewAI workflows and agents.
